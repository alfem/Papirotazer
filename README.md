# PAPIROTAZER

Seguro que has visto en alguna feria ese juego donde, a cambio de una moneda, pones a prueba tu fuerza dando un puñetazo a un *pushing ball*.

Papirotazer es la versión portable y para todos los públicos de este juego. Compite para saber quien tiene más fuerza en su dedo índice, dando un *papirotazo* (o *chorlito*, *capirotazo*, *tincazo*, *chiclazo*...) a la diana giratoria.

# COMO HACERLO

Si quieres hacerte el tuyo, necesitarás:

* Una placa Arduino UNO (o similar)
* Una tira led (tipo WS2812B, para poder encender iluminar cada LED por separado)
* Un sensor de distancia por infrarojos
* Un zumbador pasivo
* Tubos de PVC para el armazón (también puedes hacerlo de cartón o de madera)
* Unos palos de helado y unas arandelas, o una impresora 3d si quieres hacer la diana giratoria a medida
* Cablecitos con conectores tipo Dupont
* Una fuente de alimentación con su cable
